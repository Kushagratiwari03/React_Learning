# Password Generator

A React application that generates secure random passwords based on user preferences.

## Features

- Generate Random Password
- Adjustable Password Length
- Include Numbers
- Include Special Characters
- Copy Password to Clipboard

## React Hooks Used

- useState
- useEffect
- useCallback
- useRef

## Concepts Learned

- State Management
- Dependency Array
- Memoization using useCallback
- DOM Access using useRef
- Clipboard API
- Password Generation Logic

## Technologies Used

- React
- JavaScript
- Tailwind CSS
- Vite

## Learning Outcome

This project helped me understand how multiple React Hooks work together to build a real-world application.
